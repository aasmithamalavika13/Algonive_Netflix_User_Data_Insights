_**Netflix User Data Insights**_

**Project Overview**

This project analyzes Netflix dataset to understand viewing behavior, content trends, and user preferences.
Dataset
Netflix Shows Dataset from Kaggle

**Steps Performed**
Data Cleaning & Preprocessing
Exploratory Data Analysis (EDA)
Feature Engineering
Clustering using K-Means
Data Visualization

**Key Insights**
Netflix has more Movies than TV Shows
Content increased rapidly after 2015
USA produces the highest content
Most content is rated TV-MA
Clustering groups content based on duration and release year

**Tools Used**
Python, Pandas, Matplotlib, Seaborn, Scikit-learn
